# 💻 Portafolio Profesional — Javier Alfonso Suárez Duarte

Bienvenido al repositorio de mi portafolio profesional en formato **One Page**. Este sitio web fue creado con el objetivo de presentar mi perfil, trayectoria académica, habilidades técnicas y proyectos destacados como **Desarrollador Junior**.

---

## 🎨 Diseño y Paleta de Colores

El diseño fue concebido con un estilo moderno, minimalista e interactivo, aplicando una paleta de colores con contrastes cuidados y una estética visual tipo *tech/dark*:

* **Fondo Principal:** Negro Oscuro (`#0a0c10` / `#121620`)
* **Color Primario / Acento:** Azul Rey (`#1e40af` / `#2563eb`)
* **Color Secundario / Neón:** Azul Aquamarina / Turquesa (`#22d3ee`)

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico:** Estructuración accesible, optimizada y organizada por secciones.
* **CSS3:** Hojas de estilo personalizadas con *Flexbox*, *CSS Grid*, animaciones, efectos *hover* y diseño totalmente adaptativo (*Responsive Design*).
* **JavaScript (Vanilla):** Manejo dinámico del menú de navegación interactivo para dispositivos móviles y validación simple del formulario.
* **FontAwesome:** Iconografía técnica y visual.

---

## 📁 Estructura del Repositorio

| Archivo | Tipo | Descripción |
| :--- | :--- | :--- |
| `index.html` | Estructura | Página principal *One Page* con todas las secciones integradas. |
| `style.css` | Estilos | Diseño visual, variables de color y media queries *responsive*. |
| `script.js` | Lógica | Interactividad del menú navegable e interfaz. |
| `README.md` | Documentación | Información detallada del repositorio. |

---

## 📌 Secciones del Portafolio

1. **Inicio / Hero:** Presentación personal rápida con enlaces a proyectos y contacto.
2. **Sobre Mí:** Información sobre mi perfil, trayectoria y metodologías de trabajo.
3. **Habilidades:** Stack técnico de lenguajes y herramientas (HTML, CSS, JS, Python, Git, BD).
4. **Proyectos:** Selección de repositorios destacados con enlaces directos a su código fuente en GitHub.
5. **Contacto:** Formulario de comunicación y redes sociales.
